🚚 Logistics & Transportation: Fleet Performance & Delivery Efficiency Dashboard

## 📌 Project Overview

This project is an interactive **Power BI dashboard** developed to analyze fleet performance and logistics operations. It provides real-time insights into delivery performance, fuel efficiency, operational costs, and route analysis, helping logistics managers make informed decisions.

---

## 🎯 Objectives

- Monitor fleet performance using key operational KPIs.
- Track on-time delivery performance across different routes.
- Analyze fuel efficiency trends over time.
- Evaluate transportation costs using Cost per KM.
- Improve operational efficiency through interactive data visualization.

---

## 🛠 Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel

---

## 📂 Dataset

The dashboard is built using logistics operational data containing:

- Vehicle Information
- Trip Details
- Delivery Status
- Route Information
- Fuel Consumption
- Distance Travelled
- Maintenance Cost
- Delivery Date

---

## 📊 Dashboard Features

### Interactive Filters

- Vehicle Type
- Delivery Status
- Route
- Delivery Date

### KPI Cards

- Fuel Efficiency (KM/L)
- On-Time Delivery Percentage
- Cost per KM
- Total Trips

### Visualizations

- Monthly Fuel Efficiency Trend
- Fleet Route & Delivery Performance Map
- On-Time Delivery Percentage by Route
- Interactive KPI Dashboard

---

## 📐 DAX Measures

The following measures were created:

- Fuel Efficiency (KM/L)
- On-Time Delivery Percentage
- Cost per KM
- Total Trips

---

## 📈 Key Insights

- 60% of deliveries were completed on time.
- Average fuel efficiency is **12 KM/L**.
- Total completed trips during the selected period: **50**.
- Average operating cost is **10.05 per KM**.

## 💡 Business Value

This dashboard enables logistics managers to:

- Monitor fleet performance in real time.
- Identify underperforming delivery routes.
- Improve fuel efficiency.
- Reduce transportation costs.
- Support data-driven operational decisions.
